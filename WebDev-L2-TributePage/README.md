# 🌟 Tribute Page – Ratan Naval Tata

A responsive and visually engaging tribute webpage dedicated to **Ratan Naval Tata**, one of India's most admired industrialists, philanthropists, and visionary leaders. This project showcases his inspiring journey, achievements, leadership values, contributions to society, and lasting legacy through a clean and modern web interface.

---

## 📌 Project Overview

This Tribute Page was developed using **HTML5** and **CSS3** as part of the **Oasis Infobyte Web Development Internship**. The webpage presents important milestones in Ratan Tata's life while demonstrating responsive web design, structured layouts, and modern styling techniques.

---

## ✨ Features

- 🎨 Modern and responsive user interface
- 🖼️ Hero section with profile image and introduction
- 📖 Biography and personal information
- ❤️ "What I Adore About Him" section
- 🏆 Achievements timeline
- 💼 Leadership principles
- 🏢 Showcase of Tata Group companies
- 🌍 Contributions to society
- 📸 Inspirational photo gallery
- 🌟 Legacy section
- 💬 Tribute message
- 📱 Mobile-friendly responsive layout
