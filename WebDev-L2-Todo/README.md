# 📝 To-Do Web Application

A responsive and modern **To-Do Web Application** built using **HTML5, CSS3, and JavaScript**. The application helps users organize their daily tasks by allowing them to add, edit, complete, and delete tasks while automatically saving all entries for future sessions.

---

## 📌 Project Overview

This project is designed to improve productivity by providing a clean and intuitive task management interface. Tasks are categorized into **Pending** and **Completed** sections, making it easy to track progress throughout the day. The application automatically saves tasks locally, ensuring that data persists even after the browser is refreshed.

---

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🔄 Move completed tasks to a separate section
- 🗑️ Delete tasks
- 💾 Automatic task saving
- 📅 Displays current date
- 📂 Organizes tasks into Pending and Completed lists
- 📝 Shows task creation and completion timestamps
- 📱 Responsive design for desktop and mobile devices
- 🎨 Clean ledger-inspired user interface
- ⚡ Smooth animations and interactive effects

---

## 📋 Application Workflow

1. Enter a task in the input field.
2. Click **Add Task** to create a new entry.
3. Edit tasks whenever needed.
4. Mark tasks as completed to move them to the Completed section.
5. Delete tasks that are no longer required.
6. All changes are automatically saved for future visits.
