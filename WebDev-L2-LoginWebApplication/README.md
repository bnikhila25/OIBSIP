# 🔐 Login Authentication System

A modern and responsive **Login Authentication System** built using **HTML5, CSS3, and JavaScript**. The application allows users to register, securely log in, maintain a browser session using Local Storage, and access a protected dashboard—all without requiring a backend server.

---

## 📌 Project Overview

This project demonstrates a complete client-side authentication workflow with an attractive and responsive user interface. User credentials are securely handled within the browser using password hashing (SHA-256 with salt), Local Storage, and Session Management.

---

- 👤 User Registration

---

## 🔄 Application Flow

1. Create a new account.
2. Enter a username, email, and secure password.
3. Password is hashed with SHA-256 and stored securely in Local Storage.
4. Login using your username or email.
5. Upon successful authentication, access the protected dashboard.
6. Logout to end the current session.
