# OIBSIP - Web Development Level 2 Projects

This repository contains the projects completed as part of the **Oasis Infobyte Internship (OIBSIP)** under the **Web Development - Level 2** track.

## 📂 Projects

---

### 1. Calculator
A modern calculator application with a clean and responsive user interface for performing basic arithmetic operations.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

---

### 2. Tribute Page
A responsive tribute webpage built using **HTML5** and **CSS3** to showcase the life and achievements of an inspiring personality.

**Technologies Used:**
- HTML5
- CSS3

---

### 3. To-Do Web Application
A task management application that allows users to add, edit, delete, and mark tasks as completed, helping them organize their daily activities efficiently.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript

---

### 4. Login Authentication System
A simple client-side authentication system featuring user registration, login validation, and a protected dashboard using browser storage.

**Technologies Used:**
- HTML5
- CSS3
- JavaScript (Local Storage)

---

## 🚀 How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/OIBSIP.git
   ```

2. Open the desired project folder.

3. Open the HTML file in your browser or use **Live Server** in Visual Studio Code.
