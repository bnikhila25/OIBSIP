# 🌟 Tribute Page – Ratan Tata

A responsive and visually appealing tribute webpage dedicated to **Ratan Naval Tata**, one of India's most respected industrialists, philanthropists, and visionary leaders. This project highlights his life, achievements, leadership principles, contributions to society, and enduring legacy through an elegant and modern web design.

---

## 📌 Project Overview

This tribute page was created using **HTML5** and **CSS3** with a focus on responsive design, clean layout, modern typography, and smooth user experience. The webpage celebrates the inspiring journey of Ratan Tata while demonstrating front-end web development skills.

---

## ✨ Features

- 🎨 Modern and elegant UI design
- 📱 Fully responsive layout for desktop, tablet, and mobile devices
- 🖼️ Hero section with profile image and introduction
- 📖 Biography section
- ❤️ "What I Adore About Him" cards
- 🏆 Achievements timeline
- 💼 Leadership principles section
- 🏢 Showcase of Tata companies
- 🌍 Contributions to society
- 🖼️ Responsive image gallery
- 🌟 Legacy section
- 💬 Inspirational tribute message
- 🎯 Smooth scrolling and hover animations
